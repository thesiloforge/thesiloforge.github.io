Pipeline

From script to master file.

Execution runs locally from start to finish. Audio files are validated, synthesized, aligned, normalized, and packaged without leaving your workstation.

1

Preflight & Validation

Checks system dependencies (FFmpeg, FFprobe, and local ComfyUI availability), verifies that referenced audio assets exist, and validates script limits (pan, gains, pacing, and line index bounds).

2

Audio Synthesis

Connects to a local ComfyUI instance via HTTP and WebSocket. Dispatches character voices, dialogue takes, and background cues through engine-specific workflow templates (such as Breeze, CosyVoice, or Stable Audio).

3

Stem Normalization & Cache

Measures each audio stem under EBU R128 and adjusts it to a calibrated reference level (Dialogue: -20 LUFS, Music: -28 LUFS, Ambience: -40 LUFS, SFX: -22 LUFS). Results are saved in lufs.yaml to skip re-measuring unchanged files.

4

Timeline Mixing & Two-Pass Mastering

Calculates track positions based on measured audio durations and dialogue pacing. Builds an FFmpeg filter chain that handles panning, acoustic room presets, dialogue ducking envelopes, two-pass loudness normalization, and peak limiting.

5

Container Packaging

Exports a 24-bit FLAC master alongside release deliverables: 320 kbps MP3 with ID3v2 tags and an M4B audiobook file with chapter markers and embedded cover art.

Capabilities

Signal processing defined in script.

Audio properties are declared directly in text or edited through dedicated application panels. The pipeline builds the FFmpeg filter chains automatically.

YAML scripts and desktop editor

Characters, dialogue lines, background audio, music cues, Foley, and mastering values are stored in a human-readable YAML document. The Avalonia desktop interface provides visual forms and an in-app player for every entry.

Granular and batch generation

Synthesize the entire production at once or regenerate single lines, character voices, and audio cues on demand. Unaltered stems are reused directly to save GPU cycles.

Interchangeable production profiles

Switch targets with a single setting. Includes presets for European broadcast standards (EBU R128 / BBC Radio Drama: -23 LUFS, -1.5 dBTP, LRA 9) and commercial digital distribution (Audible / ACX: -20 LUFS, -3.0 dBTP, LRA 6).

Spatial and acoustic filtering

Static panning, dynamic pan sweeps from start to end positions, distance attenuation, and occlusion are calculated per item. Environment tags (room, hall, cave, telephone) configure delay, filter, and reverb parameters in FFmpeg.

Timeline-based dialogue ducking

Music and ambience stems duck under speech using gain curves calculated directly from dialogue boundaries and pauses, avoiding pumping artifacts during short pauses.

Multi-format delivery and tagging

Generates distribution assets directly: 24-bit FLAC archive masters, 320 kbps MP3 files with ID3v2 tags, and M4B audiobook containers with chapter timecodes and embedded artwork ready for catalog ingest.
