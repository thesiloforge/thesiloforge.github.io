Pipeline

From script to master file.

Every stage runs locally on your machine from a single command or UI action. No API keys, no cloud queues, no per-minute compute fees.

1

Parse & Validate

Reads the YAML script and validates bounds: pan ranges, reverb levels, ducking decay limits, chapter order, and character voice mappings.

2

Render

Sends lines and cues to a local ComfyUI instance over HTTP and WebSocket, injecting prompts, reference voices, seeds, and output file paths into the generation graph.

3

Normalize Stems

Measures stems under EBU R128 and adjusts them to fixed internal levels (Dialogue: -20 LUFS, Music: -28 LUFS, Ambience: -40 LUFS, SFX: -22 LUFS). Caches measurements in lufs.yaml to skip unchanged files.

4

Mix & Master

Builds a complex ffmpeg filter graph for spatial placement, environment reverb, frame-evaluated ducking envelopes, two-pass loudness normalization, and peak limiting.

5

Package

Writes distribution files: 24-bit FLAC master, MP3 with ID3v2 tags, and M4B audiobook with chapters, metadata, and embedded artwork.

Capabilities

Signal processing defined in script.

Audio properties are declared directly in text. The pipeline calculates DSP filters and renders the tracks without manual timeline slicing in a DAW.

Plain text production scripts

Characters, dialogue lines, background audio, music cues, Foley, pan curves, and mastering targets live in a single versionable YAML file tracked via git.

Local workflow dispatch

Mutates workflow JSON templates in memory and controls local ComfyUI execution via WebSocket. Seeds, instructions, and target directories are injected on each request.

Model transformers

Decoupled workflow transformers support multiple TTS and audio engines. Switch synthesis backends by swapping workflow templates without modifying the parsing core.

Spatial and acoustic filtering

Pan, distance roll-off, occlusion, and tempo adjustments are configured per line. Environment tags (room, hall, cave, telephone) generate parametric delay and reverb chains directly inside ffmpeg.

Timeline ducking without sidechain pumping

Replaces reactive sidechain compressors with mathematical volume envelopes evaluated per audio frame against speech boundaries. Hysteresis thresholds hold the ducked state across short pauses to avoid fluttering.

Tagged distribution packages

Generates FLAC masters, MP3 with ID3v2 metadata, and M4B containers with chapter marks, cover artwork, and audiobook container flags without redundant transcoding.
