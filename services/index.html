Desktop control software for CNC plasma tables and industrial equipment. Includes serial communication layers (RS-232/485), G-code parsers, motion buffer synchronization, real-time command overrides (jogging), torch height control (THC) with real-time voltage monitoring, and reactive state machines handling critical hardware interrupts such as arc voltage loss.

JavaFX Serial Protocols (RS-232/485) State Machines Hardware Buffering Torch Height Control

Unattended Kiosks & Hardware Peripherals

Touch-first desktop client applications designed for continuous 24/7 operation without supervision. Covers integration of payment terminals (Valina) and electronic locker systems (Kerong) over asynchronous communication, automated recovery from peripheral dropouts, and checkout logic (voucher validation, VAT-aware pricing, multi-currency formatting).

JavaFX Payment Terminals Peripheral I/O Fault Recovery Native Installers

Local Processing Pipelines & Media Engineering

Desktop workstation software that runs compute-intensive audio workflows locally, built as my own product, ScriptCast. Includes FFmpeg filter graph generation, EBU R128 loudness calibration, HTTP and WebSocket integration with a local ComfyUI instance, and timeline-based signal processing.

FFmpeg / FFprobe EBU R128 Standards WebSocket Clients Audio DSP Envelopes Avalonia UI

Enterprise Middleware & Local Sync Engines

Data integration clients synchronizing accounting systems (Sage) and SQL Server databases with external APIs. Focus on decoupled MVVM architectures, multi-threaded background processing that preserves UI responsiveness, schema migrations, and local SQLite caching.
