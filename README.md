# thesiloforge.github.io

Public website for **The Silo Forge** — an independent software workshop building local-first, offline-capable engineering tools.

Live at: **[thesiloforge.com](https://thesiloforge.com)**

---

## Structure

```
thesiloforge.github.io/
├── CNAME                    # custom domain: thesiloforge.com
├── index.html               # hub / landing
├── 404.html                 # custom error page (applies to whole domain)
├── favicon.svg              # primary icon (modern browsers)
├── favicon.ico              # legacy fallback (Safari, older browsers)
├── apple-touch-icon.png     # iOS home screen icon (180x180)
├── favicon-32x32.png        # Android/desktop PNG fallback
├── favicon-16x16.png        # small PNG fallback
├── site.webmanifest         # PWA manifest (generated by favicon tool)
├── robots.txt               # crawler rules
├── sitemap.xml              # URL index for search engines
├── logstation/
│   └── index.html           # LogStation product landing
└── scriptcast/
    └── index.html           # ScriptCast product landing
```

## Deployment

Hosted on **GitHub Pages** with a custom domain served over HTTPS.

- **DNS**: managed at Porkbun. Apex (`thesiloforge.com`) uses 4 A records pointing to GitHub Pages IPs. `www` uses a CNAME to `thesiloforge.github.io`.
- **HTTPS**: automatically provisioned by GitHub Pages (Let's Encrypt).
- **Deploy**: any push to `main` triggers an automatic rebuild. No build step; plain static HTML.

## Editing content

Each page is a single self-contained HTML file with inline `<style>` and no external JS (except a one-line year script in the footer). To edit:

1. Open the relevant `index.html` in the GitHub web editor or clone locally.
2. Modify content directly.
3. Commit. GitHub Pages rebuilds within ~1 minute.

Shared design tokens (colors, fonts) are duplicated across pages by design. There is **no shared stylesheet** — each page is intentionally self-contained so any one can be edited or replaced without touching the others.

## Product landings

- **LogStation** — desktop log investigation workstation. Accent color: `#00D9A3`.
- **ScriptCast** — local-first audio drama production pipeline. Accent color: `#14B8A6`.

The hub uses a neutral palette so each product's accent stands out on its card.

## Regenerating the favicon

If the icon ever changes:

1. Replace `favicon.svg` with the new vector.
2. Run the new SVG (or a 512×512 PNG) through [realfavicongenerator.net](https://realfavicongenerator.net).
3. Replace `favicon.ico`, `apple-touch-icon.png`, `favicon-32x32.png`, `favicon-16x16.png`, and `site.webmanifest`.

## Local development

No build step. To preview:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

Or simply open `index.html` in a browser.
